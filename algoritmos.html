ORDENAÇÃO 01

Bubble Sort

O Bubble Sort é um algoritmo de ordenação que compara elementos vizinhos e realiza trocas quando estão fora de ordem. A cada passagem, o maior elemento restante é deslocado para o final do conjunto.

ORDENAÇÃO 02

Insertion Sort

O Insertion Sort organiza os elementos inserindo cada valor em sua posição correta dentro da parte já ordenada do conjunto. Para isso, desloca os elementos maiores até encontrar o local adequado.
