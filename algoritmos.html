01

Bubble Sort

O Bubble Sort, também conhecido como método da bolha, é um algoritmo de ordenação baseado na comparação de elementos adjacentes de uma lista. Seu funcionamento consiste em percorrer o conjunto de dados várias vezes, comparando pares de elementos consecutivos e trocando suas posições sempre que estiverem na ordem incorreta. Na ordenação crescente, por exemplo, se o elemento atual for maior que o próximo, ambos trocam de posição. Esse processo faz com que os maiores valores avancem gradualmente para o final da lista, como se estivessem subindo à superfície, o que explica o nome do algoritmo. Ao concluir cada passagem, pelo menos um elemento ocupa definitivamente sua posição correta. As passagens são repetidas até que todos os elementos estejam ordenados. Uma característica importante do Bubble Sort é sua simplicidade de implementação e compreensão, tornando-o útil para fins didáticos e para demonstrar conceitos fundamentais de ordenação. Entretanto, seu desempenho é limitado quando aplicado a grandes conjuntos de dados: sua complexidade de tempo média e de pior caso é O(n²), pois pode realizar um número elevado de comparações e trocas. Sua complexidade no melhor caso pode ser O(n), caso seja implementada uma verificação que identifique quando nenhuma troca ocorreu durante uma passagem, indicando que a lista já está ordenada. Além disso, é um algoritmo estável, pois preserva a ordem relativa de elementos com valores iguais, e realiza a ordenação in-place, sem exigir uma estrutura auxiliar proporcional ao tamanho da lista.

02

Insertion Sort

O Insertion Sort, também conhecido como método de ordenação por inserção, é um algoritmo de ordenação que organiza os elementos de uma lista construindo gradualmente uma sequência ordenada. Seu funcionamento consiste em percorrer o conjunto de dados a partir do segundo elemento, considerando que o primeiro já está ordenado. A cada etapa, o algoritmo seleciona um elemento, chamado de chave, e compara seu valor com os elementos anteriores, deslocando para a direita aqueles que forem maiores que ele, até encontrar a posição correta para inseri-lo. Esse processo se assemelha à maneira como organizamos cartas de um baralho na mão: selecionamos uma carta e a inserimos no local adequado em relação às demais. A operação é repetida até que todos os elementos tenham sido analisados e inseridos em suas respectivas posições, resultando em uma lista completamente ordenada. Uma característica importante do Insertion Sort é sua simplicidade e eficiência em conjuntos pequenos de dados ou listas que já estejam parcialmente ordenadas. Sua complexidade de tempo média e de pior caso é O(n²), pois, dependendo da disposição inicial dos elementos, pode ser necessário realizar diversas comparações e deslocamentos. Entretanto, seu melhor caso é O(n), quando a lista já está ordenada, pois cada elemento precisa apenas de uma comparação para confirmar sua posição. Além disso, é um algoritmo estável, pois preserva a ordem relativa de elementos com valores iguais, e realiza a ordenação in-place, sem exigir uma estrutura auxiliar proporcional ao tamanho da lista.
