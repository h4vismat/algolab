ENTENDA A EFICIÊNCIA

Complexidade de algoritmos.

Como o custo de execução de um algoritmo cresce conforme o tamanho da entrada?

CONCEITO FUNDAMENTAL

Big O

Uma forma de descrever o crescimento do custo de um algoritmo, especialmente quando a quantidade de dados aumenta.

01 — INTRODUÇÃO

O que é complexidade?

A complexidade de um algoritmo representa a quantidade de recursos computacionais necessários para sua execução. Ela permite analisar como o desempenho muda conforme o tamanho da entrada aumenta.

Tempo

Analisa como a quantidade de operações realizadas pelo algoritmo cresce conforme o tamanho da entrada.

Espaço

Analisa a quantidade de memória adicional necessária para a execução do algoritmo.

02 — CLASSES DE COMPLEXIDADE

Como o custo cresce?

As classes de complexidade descrevem diferentes padrões de crescimento do custo de um algoritmo.

O(1)

Constante

O custo permanece independente do tamanho da entrada.

O(log n)

Logarítmica

O crescimento ocorre de maneira lenta conforme a entrada aumenta.

O(n)

Linear

O custo cresce proporcionalmente ao tamanho da entrada.

O(n log n)

Linearítmica

Combina crescimento linear e logarítmico.

O(n²)

Quadrática

O custo cresce proporcionalmente ao quadrado do tamanho da entrada.

O(2ⁿ)

Exponencial

O custo cresce rapidamente conforme a entrada aumenta.
03 — COMPARAÇÃO DOS ALGORITMOS

Bubble Sort × Insertion Sort

Compare o comportamento dos dois algoritmos de ordenação estudados no projeto em diferentes cenários de execução.

Algoritmo Melhor caso Caso médio Pior caso
Bubble Sort O(n) O(n²) O(n²)
Insertion Sort O(n) O(n²) O(n²)

Ambos os algoritmos apresentam complexidade quadrática nos casos médio e pior. Entretanto, quando a entrada já está ordenada, os dois podem apresentar desempenho linear.
