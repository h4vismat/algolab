Algolab — Visualizador de Algoritmos

O Algolab é uma aplicação web desenvolvida com o objetivo de facilitar o aprendizado de algoritmos por meio de visualizações passo a passo. O sistema permite explorar algoritmos de ordenação, compreender seu funcionamento e consultar suas respectivas complexidades por meio da notação Big O.
